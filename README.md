# Блицкриг

Приложение для **Geometry Dash**, предназначенное для ведения прохождения уровней тактикой блицкрига.

> **Текущая версия: Alpha 0.1.0**

## Возможности

- 📋 Создание и хранение таблиц уровней.
- 🎯 Добавление ранов и стартовых позиций.
- 🔢 Учёт количества попыток.
- 📝 Добавление заметок к ранам.
- ⚡ Генератор блицкрига по стартовым позициям.
- 📋 Копирование и вставка данных через буфер обмена.
- 🎨 Несколько тем оформления.
- 🌐 Настройки языка.
- 🔍 Изменение масштаба интерфейса.
- 💾 Автоматическое сохранение данных в SQLite.
- 🔄 Перенос базы данных в `%LocalAppData%` для сохранения данных между обновлениями приложения.

## Технологии

- **C#**
- **WPF**
- **.NET 10**
- **SQLite**
- **Microsoft.Data.Sqlite**

## Установка

1. Скачайте последнюю версию из раздела **Releases**.
2. Распакуйте архив.
3. Запустите `BlitzkriegWPF.exe`.

При первом запуске база данных автоматически создаётся/переносится в папку `%LocalAppData%\BlitzkriegWPF`.
