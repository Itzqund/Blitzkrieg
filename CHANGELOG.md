# История изменений

Здесь собраны изменения начиная с `v0.1.0-alpha`. Запланированные функции вынесены в план версий и не перечисляются как уже реализованные.

## v0.2.0-alpha

### Интеграция с внутриигровым модом

- Добавлена привязка таблицы приложения к JSON-сохранению по корневому `id`.
- Название уровня для связанной таблицы берётся из `profileName` сохранения.
- Повторная привязка уже используемого `id` не создаёт дубликат таблицы.
- Добавлена синхронизация при запуске и автоматическая проверка примерно раз в минуту.
- Реализована двусторонняя синхронизация: мод имеет приоритет для игровых данных, заметки приложения сохраняются со стороны приложения.
- Запись изменений из приложения откладывается, пока запущен Geometry Dash, чтобы не перезаписать файл во время игры.
- JSON сохраняется в компактном виде, одной строкой, без форматирующих отступов.
- Неизвестные приложению поля JSON сохраняются, чтобы не терять данные, нужные моду или будущему функционалу статистики.
- Добавлено хранение до трёх последних проверенных резервных копий каждого связанного сохранения в SQLite.
- При повреждении или отсутствии исходного файла данные резервной копии используются для работы приложения; оригинал автоматически не перезаписывается.

### База данных и сохранность данных

- Структура базы переведена на связанные сущности `Completions`, `Stages` и `Runs`; для связанных сохранений используются `LinkedSaves` и `SaveBackups`.
- Добавлены поля этапов для отметки выполнения и заметки.
- Реализована миграция существующей базы старого формата с предварительным резервным копированием файла БД.
- База пользователя хранится в `%LocalAppData%\Blitzkrieg\BlitzkriegDB.db`; настройки приложения находятся отдельно.
- Для диапазонов сохраняются точные значения начала и конца. Округление вниз применяется только при отображении процентов в таблице.

### Таблицы и прогресс

- Количество попыток этапа вычисляется автоматически как сумма попыток всех его ранов.
- Добавлены правила последовательного закрытия ранов и этапов, чтобы нельзя было отметить этап выполненным до закрытия всех его ранов или перейти к следующему этапу раньше времени.
- При обновлении данных сохраняются позиции прокрутки таблиц.
- Ширина рабочих столбцов ограничивается размерами текста; столбец заметок автоматически подстраивается под содержимое и не изменяется вручную.
- Последовательность строк формируется по этапам: строка этапа, его раны, затем следующий этап.

### Генератор и интерфейс

- Генератор формирует блицкриг по стартовым позициям и показывает результат.
- Добавлены команды копирования стартовых позиций и результата, вставки из буфера обмена и очистки полей.
- Переключение панели генератора ускорено за счёт повторного использования интерфейса вместо полного пересоздания таблиц.
- Добавлены темы Blue, Charcoal и Emerald, переключение русского и английского языков, настройка масштаба интерфейса.
- Настройки темы, языка и масштаба сохраняются между запусками.
- Положение, ширина и высота окна сохраняются при закрытии; состояние максимизации восстанавливается при следующем запуске.
- Увеличена область границы окна, за которую можно захватить и изменить размер.
- Исправлено поведение максимизированного окна, из-за которого могла обрезаться верхняя панель.
- Добавлено сохранение порядка таблиц после перезапуска и ручная перестановка таблиц.

### Внутренняя организация проекта

- Разделена работа с базой данных, JSON-сохранениями и синхронизацией.
- Добавлены отдельные классы для документа сохранения мода, синхронизации и настроек приложения.
- Комментарии в исходных файлах приведены к русскому языку.
- Обновлена документация проекта.

## v0.1.0-alpha

Первая альфа-версия с базовым функционалом приложения:

- Создание и ведение таблиц для уровней Geometry Dash.
- Отображение этапов и ранов.
- Редактирование отметок выполнения, количества попыток и заметок.
- Генерация блицкрига по стартовым позициям.
- Копирование и вставка данных через буфер обмена.
- Сохранение данных в SQLite.
- Несколько тем оформления, переключение языка и изменение масштаба интерфейса.
